## Plan Upgrade Matrix

- **Free → Student**: Unlocks persistent user profile memory, STAR drills, salary coach, education domain pack, and 10GB vault storage.
- **Student → Personal**: Unlocks long-term semantic memory, Saarthi custom voice persona, real-time voice, automated browser, code sandbox, and 50GB vault storage.
- **Personal → Power**: Unlocks interactive terminal, Git/GitHub integration, computer control, autonomous multi-step agents, deep paper research, and all 10 domain packs.
- **Power → Teams / Enterprise**: Unlocks shared team memory, RBAC, audit logging, and enterprise SSO/SAML authentication.
