# Saarthi Universal AI Companion User Workflow Guide

## Daily Workflow Guide

### 1. Home Command Center
Open Saarthi to see your consolidated **Command Center**:
- **Greeting & Active Target**: Personalized greeting with your active profile and target role.
- **Active Project & Task Graph**: Real-time progress bars for active cross-domain tasks.
- **Pending Approvals**: 1-click permission checkpoints for consequential actions.
- **Proactive JARVIS Notices**: Non-intrusive opportunities and deadline alerts.

### 2. Working Across Domains
Simply ask Saarthi any query:
- *"Analyze these archaeological excavation photographs, compare them with historical records, research similar findings and prepare a report."*
- Saarthi will automatically route across **Archaeology → Vision → History → Research → Writing**, displaying the transition breadcrumb and explicit evidence handoffs.

### 3. Voice Control
Speak naturally to Saarthi:
- *"Saarthi, research solid state batteries."*
- *"Saarthi, why did you switch to history?"*
- *"Saarthi, remember I prefer Python 3.14."*
- *"Saarthi, approve this step."*

### 4. Memory & Personalization
- Use the **Persistent Memory** view or type *"remember [fact]"* / *"forget [query]"*.
- Inspect provenance for any remembered fact (`USER_EXPLICIT`, `SOURCE_DERIVED`, `OBSERVED`, `MODEL_INFERENCE`).
