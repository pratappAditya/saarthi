## 3. Four Distinct UI Experience Modes

The release candidate supports 4 distinct visual experience shells accessible from Settings:
1. **SIGNATURE**: Minimalist glassmorphism interface with dark mode hues.
2. **FORGE**: High-contrast, dense engineering dashboard optimized for power users.
3. **PULSE**: Dynamic, color-accented modern career studio.
4. **AURORA**: Vibrant ambient glow interface with smooth transitions.

All 9 core views (**Dashboard**, **Resumes**, **ATS Analysis**, **Tailoring**, **Applications**, **Interview Prep**, **Career Copilot**, **Settings**, **Billing**) operate with 100% functional parity across all 4 experience modes.
