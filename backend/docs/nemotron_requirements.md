# Nemotron Hardware & System Requirements

## Overview
System requirements, RAM/VRAM allocations, and storage specifications for hosting `nemotron-3-nano:4b` locally via Ollama.

---

## Hardware Specification Matrix (Section 10)

| System Resource | Minimum Requirement | Recommended Specification | Hardware Audit Status |
| :--- | :--- | :--- | :--- |
| **System RAM** | 8 GB RAM | 16 GB RAM | `SUPPORTED` |
| **Available Free RAM** | 4 GB Free RAM | 8 GB Free RAM | `SUPPORTED` |
| **GPU / VRAM** | CPU Offload Supported | 4 GB VRAM (NVIDIA CUDA) | `MARGINAL (CPU Fallback)` |
| **Disk Storage** | 3.5 GB Free Disk Space | 10 GB SSD Storage | `SUPPORTED` |
| **Operating System** | Windows 10/11 (x64) | Windows 11 (x64) | `SUPPORTED` |
