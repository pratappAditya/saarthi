# Saarthi First-Run AI Setup & Onboarding Flow

## Onboarding Architecture

```
Saarthi Installation
       ↓
Step 1: Welcome & Local Privacy Assurance
       ↓
Step 2: Hardware Detection & Ollama Check
       ↓
Step 3: User Consent for Ollama & Model
       ↓
Step 4: Real-time Model Download & Installation
       ↓
Step 5: Minimal Health Verification Test
       ↓
Saarthi AI Ready!
```

## Consented Installation Principles
- Zero automatic background downloads.
- User must click explicit action buttons ([Accept & Install], [Install Recommended Model]) before network or disk operations occur.
- Progress feedback displays real-time state: Downloading -> Verifying -> Initializing -> Testing.
