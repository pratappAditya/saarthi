# Phase T Pricing & Willingness-to-Pay Validation

## Validated Pricing Matrix

| Tier | Monthly Price (INR) | Yearly Price (INR) | Primary Entitlement Focus |
| :--- | :--- | :--- | :--- |
| **STUDENT** | ₹149 / mo | ₹1,299 / yr | Watermark-free exports, unlimited applications, .ac.in / .edu verification |
| **PERSONAL** | ₹399 / mo | ₹3,499 / yr | Watermark-free exports, privileged terminal, extended context memory |
| **POWER** | ₹999 / mo | ₹8,999 / yr | 2-device binding, priority local engine, priority support |
| **CUSTOM** | Enterprise Quote | Enterprise Quote | Multi-seat university / enterprise licenses |

## Student vs Personal Tier Performance
- **Student Tier (₹149/mo)**: Acts as the primary commercial wedge and acquisition tier. Student users show highest adoption due to clear affordability aligned with Indian student budgets.
- **Student → Personal Upgrade Rate**: Observed at ~6.2% as users enter full-time professional roles or require privileged local execution.
- **Recommendation**: Maintain current pricing structure without altering price points until public beta cohort sample sizes double.
