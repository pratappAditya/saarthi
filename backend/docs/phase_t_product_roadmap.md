# Phase T Product Roadmap & Feature Prioritization

## Prioritization Framework
Features are ranked strictly by empirical correlation with conversion, retention, and security integrity. No feature is added based on competitor parity alone.

---

## Prioritized Feature Backlog

### P0 — Directly Affects Conversion, Retention & Security (Immediate Priority)
1. **Seamless Watermark Re-Export Flow**: One-click re-export of previously generated documents without watermark immediately upon license key activation.
2. **Payment Failure Auto-Retry & Recovery UI**: Self-serve billing portal for failed UPI/Card webhooks to prevent unnecessary churn.
3. **Local Model Hardware Diagnostics**: Automated GPU/RAM capability check during onboarding to optimize local Ollama speed.

### P1 — Strong Measurable Value (Next Cycle)
1. **Multi-Template Markdown Resume Formats**: 3 additional ATS-validated resume layouts (Modern, Executive, Academic).
2. **Bulk Application CSV Import/Export**: Import external job application lists into the career tracker.
3. **Automated Follow-Up Reminder Notifications**: Local OS desktop notifications for upcoming recruiter follow-up dates.

### P2 — Useful Non-Critical Enhancements
1. **Interview Question Practice Audio Recorder**: Local audio recording for STAR method practice answers.
2. **Salary Benchmarking Calculator**: Anonymized local salary comparison tool by role and location.

### P3 — Nice-to-Have / Cosmetic
1. **Custom UI Color Themes**: Additional dark mode accent color schemes.
