# Saarthi Enterprise Architecture Specification (Commercially Frozen)

## Overview
Saarthi Enterprise provides enterprise-grade governance, SSO/SAML interfaces, and custom deployment options. Commercially frozen (`ENTERPRISE_PUBLIC_SALE = False`).

## Architecture Features
- **Organization Hierarchy**: Multi-level department and unit grouping.
- **SSO/SAML Interface**: Modular SSO provider abstractions.
- **SCIM User Provisioning Interface**: Standardized identity synchronization.
- **Enterprise Security Policies**: Custom data retention, local network restrictions, and IP whitelist rules.
- **Enterprise Administration & Telemetry**: Dedicated audit and hardware usage monitoring.
