# Saarthi Windows Installation Guide

## System Requirements
- **Operating System**: Windows 10 / Windows 11 (64-bit)
- **RAM**: Minimum 8 GB (16 GB recommended)
- **Storage**: Minimum 5 GB free disk space
- **GPU**: NVIDIA GPU with CUDA support recommended (GTX 1650 Ti or higher; CPU fallback supported)

---

## Installation Steps

1. **Run Setup**: Double-click `Saarthi-Setup-v0.5.0.exe`.
2. **Choose Directory**: Install binaries to default Program Files or custom directory.
3. **Automatic Services Check**: Launching Saarthi automatically checks local Ollama server, backend status, and model availability.
4. **Start Chatting**: The desktop command center opens directly at `http://127.0.0.1:8000/`.
